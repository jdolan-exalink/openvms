# Agregar un idioma o un módulo de la interfaz

Cada idioma vive en su carpeta. El menú de cuenta lista los idiomas que encuentra ahí. No hay una lista fija de códigos en el código de la aplicación.

El español es el idioma de producto y el esquema de claves. Si falta una traducción, la pantalla muestra el texto en español. Si tampoco está en español, muestra la clave.

## Quick path

1. Copiá `apps/web/src/i18n/locales/es` a `apps/web/src/i18n/locales/<id>`. El `<id>` es el código de la carpeta (`fr`, `de`). Una carpeta que empieza con `_` no se publica.
2. Traducí los valores. Las claves quedan iguales.
3. Completá `meta.ts`: `label` (nombre en ese idioma), `short`, `html` (etiqueta BCP 47, por ejemplo `fr` o `pt-BR`) y `order` (posición en el menú). Sin `order`, el idioma queda después de los numerados, en orden alfabético.
4. Corré el test de paridad. Falla si a ese idioma le falta un módulo, le sobra una clave o le falta una clave del español.

## Módulo nuevo

Un módulo es un archivo por idioma (`events.ts`, `maps.ts`). La clave en pantalla es `modulo.clave`.

1. Agregá el archivo en **cada** idioma, con las mismas claves y `export default` de un objeto `as const`.
2. Importalo en `apps/web/src/i18n/modules.ts` y sumalo a `sourceModules`. Ese archivo es el único registro de módulos: define el tipo `MessageKey`.
3. En la interfaz, `useT()` y `t("modulo.clave")`. Un componente que muestra texto traducido tiene que llamar `useT()` o `useLocale()` para redibujarse al cambiar el idioma.
4. Textos compartidos (tipo de vehículo, color, estado) salen de `apps/web/src/lib/format.ts` con `translate(getLocale(), clave)`. Las listas de opciones son funciones: se leen al renderizar, no al importar el módulo.

## Details

| Tema | Decisión |
|------|----------|
| Claves | Estables y con punto (`nav.live`). El español no es la clave. |
| Descubrimiento | Vite lee `locales/*/*.ts`. Un idioma nuevo no se anota en `isLocale`. |
| Orden del menú | `order` en `meta.ts`. |
| Fechas de la UI | Usan `html` de `meta.ts` (`es-AR`, `en`, `pt-BR`). La marca de agua legal no sigue el idioma. |
| Variables | `{nombre}` en el texto, segundo argumento de `t`. |
| Reservado | Carpetas `_…` (plantillas). `meta.ts` no es un módulo de mensajes. |
| Pruebas | `test-setup` fija el idioma en español. Los tests de pantalla esperan el texto en español. |

## Checklist

- [ ] La carpeta nueva tiene los mismos archivos de módulo que `locales/es`, más `meta.ts`.
- [ ] Ninguna clave nueva quedó solo en un idioma.
- [ ] `modules.ts` importa el módulo nuevo desde `locales/es`.
- [ ] El componente que muestra el texto llama `useT()` o `useLocale()`.
- [ ] `pnpm --filter @openvms/web exec vitest run src/i18n/i18n.test.ts` pasa.
